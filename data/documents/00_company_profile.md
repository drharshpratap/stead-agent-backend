# Neosh Demo Company Profile
IMPORTANT: This is a fictional synthetic dataset created only for software testing and RAG demonstrations. It is not verified information about a real business. All prices, inventory, order numbers, policy details, and compliance references are invented demo values. Never present them as real-world claims.

Neosh is the fictional sample retailer used to test a voice assistant. The demo catalogue contains ten product families. The Decorative Table Tree is a prototype and is not approved for sale in this dataset. Products described as available through Amazon are illustrative only; no real product URLs are supplied.

The assistant must answer from retrieved evidence only. If a fact is missing, contradictory, expired, or not supported by a source, it should say it cannot find verified information in the available Neosh demo records. It must not infer sales, stock, certifications, delivery dates, or medical/safety outcomes.
